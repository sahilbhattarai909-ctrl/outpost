# 🏕️ Outpost — Outdoor Experience & Rental Marketplace

Outpost is a full-stack web application for discovering and booking unique outdoor stays and experiences.

The platform allows users to explore listings, search for experiences, create accounts, log in securely, view listing details, and make bookings.

This project was built as a hands-on learning project while following and applying concepts from **Colt Steele's Web Developer Bootcamp**, with additional customization and features developed specifically for Outpost.

---

## 🚀 Features

- 🏕️ Browse outdoor stays and experiences
- 🔎 Search listings by title, location, and category
- 📍 View detailed listing information
- 👤 User registration and login
- 🔐 Password hashing with bcrypt
- 🔑 Session-based authentication
- 📊 Protected user dashboard
- 📅 Create bookings
- 🧾 View personal bookings
- 💰 Automatic booking price calculation
- 📱 Responsive design using Bootstrap
- 🎨 Custom styling and responsive UI
- 🌐 RESTful API for listings
- 🗄️ MongoDB database integration
